# Studio Kel Nascimento — Cartão digital

Mini site (cartão digital) do Studio Kel Nascimento: serviços, localização, Instagram e WhatsApp.

## Publicar no GitHub Pages
1. Settings → Pages
2. Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save
3. O link fica em `https://<usuario>.github.io/<repositorio>/`

## Editar o conteúdo
- Abra o site e toque 5 vezes na logo (ou coloque `#admin` no fim do link).
- Edite pelo painel e clique em **Salvar e publicar**: o navegador baixa um novo `index.html`.
- No GitHub: **Add file → Upload files**, envie o `index.html` baixado e confirme (Commit).
